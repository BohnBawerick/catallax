# Interface changes

The interface-change record lives in [per-change fragments](interface-changes/). Read the [fragment guide](interface-changes/README.md) before adding a change.

Add a new fragment in the same pull request as the interface change. Do not edit this index or a shared list of entries in feature pull requests.

The migrated history uses numbered filenames to preserve the original log order, including entries whose dates are out of sequence. Each fragment retains its original date and text. New fragments use a date and a unique descriptive slug, not a shared sequence number.
