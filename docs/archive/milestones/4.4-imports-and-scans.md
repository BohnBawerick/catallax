# 4.4 imports and scans

## STEP trim

The exact STEP importer can extract a proper subrectangle from a nonplanar
equal-weight bilinear carrier. Four straight physical edges must meet at the
corners and run along the four iso-parameter rows. The usual curve, orientation,
sewing and nonintersection checks still apply. The field keeps the extracted
spline faces and their planar companion faces in a patch shell. A query on a
patch where the distance enclosure reaches zero can return `Indeterminate`.

The exchange test extends one carrier from an OpenCASCADE 8.0 export of the
M27 loft. The extension leaves the physical solid and its pcurves in place.
The test checks the extracted domain, compares containment with the B-rep and
checks signed distance at five points against the finite B-rep geometry. All
five intervals fit the STEP file's 100 pm uncertainty. The largest width is
39.5 pm. A point on the discarded extension lies 0.515388 mm outside the solid.
B-rep and field builds used 166,828 and 168,721 work units. OpenCASCADE 8.0.1
also opened the fixture as one valid six-face solid and agreed on all five
queries within 100 pm. This proves a proper trim on an exchange fixture.

## Measured scan

`fit_sphere_scan` fits the centre and radius of an isolated spherical scan.
The recipe builds an analytic sphere in the B-rep and the field. The fitter
checks every supplied point's exact placed coordinates against the written
sphere and refuses if any point exceeds the requested deviation. It measures
512 directions in reverse to report the effects of missing samples. A small cap
with insufficient spread to constrain the radius refuses.

The fixture is target 11 from experiment 1 of Frank Liebold's *Photogrammetric
data of spherical target test fields*. The GOM ATOS source mesh is in millimetres.
The fixture retains all 13,154 source vertices in the 44 mm cube centred at
`(15.7475, 89.2047, -83.8982)`, in source order. It drops triangle connectivity
and writes each coordinate to eight decimal places. The centre in this crop
comes from the dataset's target table. The fitter receives only the vertices.
The source mesh SHA-256 is
`f3721d347c10ac07af9a4f75aab80ab93d049033bc2c6ff58bf2eb4fc8d88504`.
The dataset is available under CC BY 4.0.
[Dataset](https://doi.org/10.25532/OPARA-897) · [License](https://creativecommons.org/licenses/by/4.0/)

The maximum scan-to-part deviation is 0.051628 mm against a requested
0.06 mm. The RMS is 0.015933 mm. The reverse maximum is 16.477585 mm at the
occluded rear of the mounted target. Both deviations are sampled measurements.
Fitting used 1,082,743 work units. The certified display mesh has 426,408
triangles and a 0.000874 mm chord bound. Display used 214,921 work units.

## Replay

```sh
cargo test --release -j 2 -p catallax-field --test import_trimmed_step --test scan_sphere_real -- --nocapture
```

Set `CATALLAX_SCAN_DISPLAY_OBJ` to the path for the display mesh. To compare
the existing import and scan answers on two revisions, apply the differential
test changes to the main revision, run `tools/checks/imports-differential.sh
record OUTPUT_DIR` on each, then use its `compare MAIN_DIR CANDIDATE_DIR`
command with the two result directories. the Linux timing system run matched all 66
spline import and 17 scan fit records exactly.
