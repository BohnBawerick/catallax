## 2026-10-25: convex polygon first-hit caps on stock quadrics

Pieces: features, field, recipe consumers.
Change: `AuthoredCap::compile` accepts one bounded convex rational line polygon against a stock sphere, cylinder or cone when the existing whole-enclosure proof certifies one uniform positive entry or exit branch, including separation from every stock cap trim. The exact polygon halfplanes define both finite analytic construction cells and B-rep column walls. `extrude_to` and `extrude_next` share that construction.
Why: the previous four-side rectangle gate rejected triangles, pentagons and rotated convex profiles even when their enclosing rectangle already certified the first branch.
Migration: `AuthoredCap::side_ids()` returns a slice instead of a four-element array reference. `CurvedCapped::construction` accepts a side-id slice; `build` accepts any `AsRef<[ElementId]>`, preserving existing array callers. Supply exactly one id per `side_constraints()` entry. Axis-aligned rectangles retain their existing u-min, u-max, v-min, v-max side order; other polygons retain authored segment order in either winding. `bounds()` is the rectangular proof enclosure; `side_constraints()` supplies the actual domain as exact `[a,b,c]` inequalities `a*u+b*v+c <= 0`. Callers must use those inequalities for polygon membership and origins. The existing field Plan hook consumes the same analytic cells without a topology build.

The enclosure proof remains conservative. Failure to certify its discriminant, uniform start state, finite branch or trim separation is `features.unsupported-curved-limit`, including polygons with existing hits whose enclosing rectangle crosses a silhouette. Tangencies, branch changes, general targets and oblique torus sections remain outside this slice. The [annular torus path](0171-2026-10-26-exact-annular-torus-first-hit-limits.md), its higher-degree rejection, resource defaults, tolerances and display contracts are unchanged. Native field display and requested properties remain independent consumers with their own typed refusals.
