## 2026-11-02: parallel-cylinder fillet strips and nearest straight edges

Pieces: features, application, verification
Change: B-rep fillets now admit straight generator edges between intersecting parallel circular cylinders, when the signed offset contacts stay regular and the existing end and trim proofs succeed. The strip is an exact cylinder and both contact rails are shared with the trimmed input faces. A fillet edge reference with `near` now resolves among bounded straight edges by exact distance to the closed segment, and an exact tie returns `recipe.ambiguous-reference`. Two strips that consume one arc of a shared cylinder wall return `fillet.unsupported-overflow`. Opt-in operation logs gain `fillet.contact`, `fillet.sections` and `fillet.trimming` for this case.
Why: these supports reduce to two offset circles in a normal section and need no fitted carrier, so `near` was the only thing stopping one of the two generators of a lens from being chosen on its own. Nonparallel cylinders, oblique plane and cylinder curves, curved edges and rollover stay refused. `near` among curved edges stays refused. The independent field still returns `field.fillet-contact` for cylinder pairs, because its affected-region section has straight support boundaries. Fitting does not apply to this exact reduction.
Migration: no recipe schema or function signature changes. Select the two cylinder walls with an ordinary `between` reference. Without `near` it chooses every generator between those walls, under RECIPE.md section 3.4. Consumers of operation logs must accept the new phase names. Callers that compare both kernels must expect a field refusal for these fillets. Do not read this as support for skew cylinders or general rollover.
