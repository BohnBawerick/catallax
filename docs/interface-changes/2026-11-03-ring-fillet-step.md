## 2026-11-03: STEP and a certificate for a body with a ring fillet

Pieces: step, features, cli, shapes, topology
Change: `write_step` and `write_rolling_junction_step` now answer for a body with a ring between nonparallel cylinders. The band is written with one seam, and each wall stays its exact cylinder with a chart cut. `catallax-verify` on such a recipe returns an answered manifest/4 instead of the `features.unsupported-offset-family` refusal. Its certificate has a `rolling-saddle` region for each band, `retained_target.kind` is `rolling-saddle-junction` with `saddle_faces`, and `spline` lists each band. `JunctionCertificate` gains `saddles`, which returns the new `SaddleRegion`. The result of such a fillet step now carries the `features.rolling-envelope-fit` mark with the worst fit bound. `RollingSaddle` gains `parameter_table` and `enclosed_controls`, and `RollingSaddleDefinition` gains `origin`. `saddle_rows` also accepts a rail with one vertex on it, as an export copy has.
Why: this is the fifth piece of the nonparallel cylinder slice. A part with this fillet needs a file, and `catallax-verify` needs that file and a certificate to answer.
Migration: a caller that reads marks sees one on these results, and code that took `Built` marks to be empty for a ring needs updating. A pattern's result has no base and still refuses in `catallax-verify` with `numbers.geometric-gap-unproven`. The certificate refuses, with `numbers.geometric-gap-unproven`, when a wall beside a ring has an edge that is not a circle, an ellipse or the far rail of a through bore, because it has no width bound for that edge.
