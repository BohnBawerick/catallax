# 2026-11-11: GPU batch preview evaluator and first paint

Pieces: catallax-preview (new library), catallax-field callers of the unproved preview
Change: `catallax-preview` gains a library. `batch::Evaluator` evaluates large point batches and power-of-two grids of the [unproved WGSL program](2026-11-11-unproved-gpu-preview.md) in wgpu compute shaders, and falls back to `Plan::unproved_preview_batch` when no device is given or the plan has no WGSL translation. Each `Samples` result records `Hardware::GraphicsCard` or `Hardware::Processor` with the fallback reason, plus the plan's true-distance flag. `first_paint::first_paint` samples a plan's exact material bounds on such a cell-centred grid, up to a caller's point limit (`first_paint::MAX_POINTS` by default), and extracts a surface-nets `SampledMesh`, which has no writer, no face ownership, no deviation bound and no conversion to a certified mesh. The viewer's device wrapper moves into `gpu::Gpu`. New refusal codes: `preview.dispatch`, `preview.grid-range`, `preview.grid-size`, `preview.grid-values`, `preview.gpu-range`, `preview.gpu-non-finite`, `preview.gpu-device` and `preview.mesh-size`; `preview.shader` and `field.preview-workers` keep their meanings. A new binary, `catallax-first-paint`, checks the first paint against the processor preview on P1 to P4.
Why: the field's display needs batch inside or outside and distance estimates for millions of points, and the [hardware preview decision](../ARCHITECTURE.md#unproved-hardware-preview-evaluator-decision-of-2026-11-10) allows the graphics card on the unproved preview path only.
Migration: none for existing callers; `catallax-field` and every proved route are unchanged. Graphics-card values are binary32 and may differ from the processor preview and between machines in the last digits. A non-finite graphics-card value refuses the whole batch. Grid points sit at cell centres and are exact in binary32 and binary64, so both routes evaluate the same points. Repeated runs and every dispatch size give the same bits on one device. No sample, mesh or timing from this library may feed an export, a proof or a proven measurement.
