# Optional distance implementation path

Individual entries in `catallax-operation-log/1` may contain a `path` string.
The string names the analytic offset, shell or thicken implementation that
answered. Unannotated operations omit the field. Consumers may ignore it.

This is an additive observation. It changes no manifest field, geometry,
marks, numeric question or accepted work count. Nested operation spans retain
separate paths. Recording remains disabled unless an operation log is active.

The established `OperationEntry` Debug dump keeps its original field inventory
and formatting. The public `path` field and structured operation log expose the
annotation without changing exact application outcome captures.
