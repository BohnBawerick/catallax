# STEP incidence boundary certificates

The bounded incidence derivative now proves simple planar boundaries with disjoint holes. Finite segment distances supply its feature bound. This proof covers local edge and vertex movement. It does not extend the existing convex whole-face Hausdorff certificate.

A rational spline can reduce to an exact line image when its homogeneous derivative numerator has nonnegative Bernstein coefficients and at least one positive coefficient on each span. Exact joins and ordered retained endpoints remain required. An endpoint parameter derivative may vanish, while the geometric line image stays regular and strictly ordered.

Original endpoint gaps must independently fit the 0.01 mm cap even when both the vertex and curve move. Reversing STEP curve sense preserves the natural line direction. In a spline-bearing file, analytic sibling solids can take the same measured repair path independently. Bodies are never joined.

`measure_incidence` also accepts its own `incidence_gap` refusal. Measurements use local Bezier span coordinates, so a translated or short knot interval does not inflate global polynomial coefficients. The operation allowance is unchanged.

Synthetic public STEP controls cover an inclusive cap, a larger coupled source gap, reversed sense, a concave prism, a through hole, independent sibling solids and a vanishing endpoint parameter derivative. No source model geometry is included.
