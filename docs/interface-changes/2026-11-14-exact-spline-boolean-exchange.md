# Exact rational spline boolean exchange

Ordinary recipe exchange now selects the existing manifest/5 vocabulary for
bodies whose spline faces all retain checked `RationalPatch` or
`RationalAtlas` definitions, including Boolean results without a complete
loft chart expansion. Retained section and patch-pair edges use
`intersection`. No format or tolerance changes.

This lets the side box/loft solids, through-all loft cut and M7 prism cut
reach the existing STEP writer. They still refuse with the writer's typed
coverage or trim-proof failure and publish no STEP file. The
[numbered M10 inventory](../M10-BOOLEAN-QUALIFICATION.md) records the charged
work, slower requests and remaining imported/two-spline refusals.

Native spline/line comparison also recognizes that a finite positive-weight
spline cannot equal an unbounded line. Whole-span checks and overlap-query
refusals retain their existing rules. Existing analytic answer routes and
fitted-body certificate routes are unchanged.
