# Retained Hole cap wiring

`catallax_features::hole::append_planar_cap` appends a generating numerical face from shared stock-ring and tool-section edges. The caller supplies the original plane and material sense, an unordered outer boundary and an optional bore boundary. Each boundary must form one directed closed walk. Every supplied edge is used. A branch, missing join, repeated edge or extra disconnected walk returns `hole.cap-boundary` without changing the definition or native bindings.

The 3D carriers, finite parameters and shared vertex indices remain unchanged. The function projects spline poles into the original plane frame, preserving degree, knots and weights. Finite lines retain their parameter interval. Each shared vertex supplies one declared UV position, rounded at 128 bits. The pcurves remain independent definitions for subsequent numerical admission to check against those positions. In particular, independently rounded curve endpoints do not create separate logical cap vertices.

The returned face index identifies generating data. The caller must still admit the complete closed shell under its preset tolerance and use the approximate STEP writer with its output checks. This helper grants no exact incidence, whole-body deviation bound or export authority.

The E07 skew cap uses actual compiled Hole frames and the canonical cylinder descriptor, with signed-mm interval [-99/2,99/2]. Its outer boundary joins retained original cone-ring segments to tool sections across the cylinder 4/0 seam. The original bore remains a separate inner loop. All retained cone regions remain available, including the small region near native cone u=0. The full E07 collar still requires its outer-cylinder wall fits and complete shell assembly.

The approach follows OCCT 7.9.3 [WireSplitter](https://github.com/Open-Cascade-SAS/OCCT/blob/V7_9_3/src/BOPAlgo/BOPAlgo_WireSplitter.cxx), which builds connected edge blocks before wires, and [ProjectOnPlane](https://github.com/Open-Cascade-SAS/OCCT/blob/V7_9_3/src/GeomProjLib/GeomProjLib.cxx), which projects B-spline poles. The P04 map in docs/THIRD-PARTY.md records the existing SMLib requested-domain and curve-on-surface query path. This caller retains those producer curves and domains rather than adding another intersection fitter.

Component acceptance checks both diameters, native pcurve composition, cap material, the physical native-u=0 sliver, stable keys and transfer. Removing the sliver face loses its witness. Combining the outer and bore walks into one boundary refuses without changing saved geometry. The two states use 8983439 and 9001017 work, including transfer and test witnesses, under the unchanged 20M target. The closed six-face cap/wall fixture also uses this helper for numerical admission and approximate STEP. Neither fixture establishes the complete E07 collar.
