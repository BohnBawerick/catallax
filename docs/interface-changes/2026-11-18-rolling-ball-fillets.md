## 2026-11-18: exact fillets first, refunded on refusal, then the rolling ball

Pieces: 1; features, application, import reader and display mesh; SolidDraft adapter
Change: `catallax_numbers::refund_on_refusal` runs an attempt whose refusal returns its work charges and clears an exhaustion it latched; a success keeps every charge. `catallax_features::evaluate_incremental_outcome` tries the exact fillet builders through it and hands any refusal of theirs to the rolling-ball construction. `catallax_app::build_incremental_without_display` returns the exact `EvaluatedApplicationBody` as before; `build_incremental_with_files_without_display` returns `EvaluatedApplicationOutcome`, exact or numerical. A fillet neither construction builds reports the rolling-ball refusal's code with both details, `exact path refused ...; numerical continuation refused ...`, except that a radius limit only the exact builders proved keeps `fillet.radius-too-large`, and that the exact refusal stands, its own text first, where the rolling ball could not embed the body (`features.numerical-embedding-*`); a terminal `; radius limit X mm` stays terminal. The STEP reader accepts a `TRIMMED_CURVE` whose parameter trim is exactly the domain of its B-spline basis with agreeing sense, as the numerical writer emits for native spline edges; every other trim stays `Unsupported`. `catallax_mesh::preview_step` halves a curved cell along the axis it bends along and keeps curved cells from growing far longer than wide. It no longer compares the normal of a triangle so thin that moving a corner by the chord target tilts it past the angular bound, refines a triangle no longer than the chord target, or tests the middle of a triangle side that lies on a trim, which belongs to the trim's own polyline.
Why: sending every fillet to the rolling ball made box fillets approximate and refused every operation after a fillet. The owner's pocket rim, which the exact builders refuse, needs the rolling ball with the whole allowance, and its body has to display and export through the numerical STEP file.
Migration: callers that want numerical fillets call `build_incremental_with_files_without_display` and match the outcome; callers of `build_incremental_without_display` change nothing. Code that reads fillet refusal details must take the limit from the terminal `; radius limit` suffix or `catallax_features::fillet::radius_limit`, not from the start of the detail. Preview triangle counts on cylinders, cones and tori fall; no certified mesh changes.
