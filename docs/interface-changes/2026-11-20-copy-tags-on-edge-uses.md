## 2026-11-20: edge uses carry a copy tag

Pieces: 3, 5, 7, features, import, step, boolean, cli, app (every piece that builds a `NumericalTrim` or a `NumericalNativeTrim`)
Change: `NumericalTrim` and `NumericalNativeTrim` have a new public field `tag: CopyTag`. `CopyTag` is `Independent` or `Derived { from: CopySource, rule: CopyRule, bound }`, all three new public types in `catallax_topology::numerical`. Admission does not measure a use tagged `Derived`. It records the stated bound, without the 1.1 margin, under a new check name: `trim.edge-surface-derived-bound`, or `trim.numerical-pair-edge-surface-derived-bound` on a sampled carrier. The record has one sample whose parameters are the two ends of the use. A circle or spline projected on a plane is measured whatever its tag says. A negative bound refuses with `numerical.invalid-definition`. A retained native curve's tag is the one read for its use. New public functions: `numerical::audit_derived_copies`, which runs the full check on every derived copy of a body and returns one `DerivedCopyAudit` row each, and `NumericalDefinition::reset_copy_tags`. `NumericalBody::rebuild` now resets the tag of a retained native curve unless its use in the edited definition states the same tag. `replace_surface` resets the tags of the face it edits. The tag is not written to a stored body and reads back as `Independent`, so the handover format does not change.
Why: roadmap item 3.0A, decision Q8 (section 4.4 of the Checkpoint 2 decisions). Where one copy of an edge is made from the other by an exact rule, the rule gives the gap and a measurement adds nothing. The tag also says which copy is authoritative. The rails of a fillet's blend face are the first copies tagged, see [the copy tagging note](../milestones/3.0A-copy-tagging.md).
Migration: every struct literal of the two types needs the field. Set `CopyTag::Independent` unless the code builds both copies by a rule with a known bound and has a property test that passes the audit. Code that takes a definition over from a body and changes a curve, a surface, a parameter range or a u/v end calls `reset_copy_tags` first and sets the tag of any native curve it keeps to `Independent`. Code that counts edge-surface records counts both names.
