# P0–P5 head-to-head at the 100,000,000-unit exchange default

This is a separate experiment from the [1,000,000-unit baseline](2026-10-24-head-to-head-1m.md), not a replacement or a passing reinterpretation of its refusals. Both runs use the same Catallax executable, SHA-256 `5f59d33af0fb5e86086bf8b5a46e7dd0b74b340e8860243846bbebdf8bc4711e`, built from `74bf31a8fae4e2d814cc9a4224dee401621401de`, and the same pinned SolidCraft v0.21.0 release. No kernel code or tolerance changed between the experiments. Every Catallax phase receives the same fixed 100,000,000-unit allowance.

This is a snapshot of that named commit. Later `main` feature merges, including elementary chamfer construction, are not retroactively measured by these rows.

There are thirteen public targets, one warmup and three measured alternating pairs each, on pinned core 0 with one thread. The same WSL2 host exposes 24 allowed cores. Pair-start one-minute load averages range from 0.296 to 2.411. Full load triples and process costs remain in the raw data; these are shared-machine observations, not idle-host speed claims.

Crossing-pipes is far outside the interactive target, and its edit still exhausts work. The seam edit exceeds the build-and-display budget and no longer resolves one original physical-edge reference, between `a:end` and `b:wall`. That parameter edit changes trim incidence; the recorded name failure is not, by itself, proof of an identity bug. Its original requested measurement also exceeds the complete-background-comparison target before any comparison is performed. No successful construction time is presented as a completed click.

P1 still exhausts work. The general cone and torus require certified tracing, P2 chamfer and P4 shell retain unsupported-operation refusals, and P5 reaches a non-coaxial cylinder/torus tracing refusal at its junction fillet. These are preserved as refusals, never replaced with simplified parts. The reference has the same outcome classes as the 1M experiment: it constructs more originals, but has numeric property discrepancies, lost names and native command failures.

## Separate phase measurements and correctness

Times are medians in milliseconds. Refused phases have no successful median; their latency appears in its own column. Counts exclude warmups. Property-error counts are discrepant quantities or centroid components, not distinct parts. A zero checked denominator is unmeasured. STEP opening is distinct from passing topology and expected face count; reference crossing-pipes exports fail topology validation, while many other export failures are face-count changes despite valid import.

The independent numeric allowance is diagnostic only. Passing property comparisons or 216 sampled membership points is not an exact set-equality certificate. P2/P3 original STEP and membership checks were unavailable because of the checker API error. The table now includes correctness-only saved-artifact rechecks whose STEP SHA-256 values match the original rows. Catallax P3 files pass import, topology, face count and membership; Catallax P2 remains not-run. A reference P2 membership pass is distinct from the requested CLI property comparison, which still disagrees with the independent values. No overall speed ranking is claimed.

## Data and provenance

- [Original raw rows](2026-10-24-head-to-head-100m-raw.json) retain all 52 pairs and original checker failures. Paths and machine names were normalized in transfer; numeric observations are unchanged. The old embedded summary is historical. The tables here derive from `pairs` and exclude refusal latency from successful medians.
- [Independent property rechecks](2026-10-24-head-to-head-100m-property-rechecks.json) use the fixed OpenCASCADE 8 `TopoDS.Edge` cast and the same independent P2/P3 definitions proved for the first experiment. Every original claim is compared afresh without rerunning or rewriting timing. Catallax's checked successful properties agree with the independent values. Reference measurement discrepancies are not a proof that every exact body is wrong.
- [Saved-artifact correctness rechecks](2026-10-24-head-to-head-correctness-rechecks.json) contain all 64 P2/P3 records across both work allowances, matched by run, part, sample, engine, variant and STEP hash. They do not rerun or overwrite timing. All seven successful Catallax original exports now have passing file-based checks.
- [Derived rows](2026-10-24-head-to-head-100m-summary.json) record SHA-256 pins for the raw rows, numeric rechecks and saved-artifact rechecks, per-phase outcomes/refusals, deterministic work and operations rebuilt. P5's independent OpenCASCADE fillet remains unavailable rather than being accepted from an easier construction.
- The unchanged-answer proof is the [same 477-input replay aggregate](2026-10-24-head-to-head-replay.json). This second experiment changes only the benchmark's explicit work allowance, not its input recipes or the executable.

Use the [rerun guide](../../.claude/skills/verify-catallax/scripts/head-to-head/README.md) with `--max-work 100000000` and a fresh output directory. Keep the 1M dataset beside it. The comparison lives only in development tooling and adds no work to an application edit.
