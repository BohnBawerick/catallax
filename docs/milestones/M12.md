## Area coverage still missing

`a_fitted_blend_area_encloses_the_definition_and_the_carriers` passes, but its
current assertions require one `measure.area-of-definition` mark from both
`volume_area_centroid` and `area`. For the P5 disjoint-cut fixture, both return
the definition's interval
`[6774.950656257191, 6774.950670840658] mm²`, width
`0.00001458346645310306 mm²`. The requested absolute accuracy is `0.001 mm²`.
The interval is narrow enough for the definition; it does not bound the fitted
carriers' area. Their mouth-row cells exhaust `shapes.area-cell-budget` because
regularity is unproved. A distance fit bound cannot replace an area bound.

The earlier [area interface note](../interface-changes/2026-11-12-fitted-area-carriers.md)
records a 186 mm² carrier enclosure. The current regression explicitly retains
the definition-only mark instead of returning that coarse unmarked answer.
The historical note is not a passing carrier-area result for this exit source.
