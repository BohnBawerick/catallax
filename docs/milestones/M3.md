## Repeat the kernel export check

`tools/research/m3_acceptance.py` runs the four near-miss variants at their existing 1M scoreboard allowance, then P2/P3 originals, parameter edits, name checks and qualified B-rep STL requests at the existing 20M application allowance. Print accuracy is the existing default, 0.01 mm. The original recipes are unchanged. It compares manifests, deterministic work, STEP bytes and mesh bytes at 1/2/4 workers and kernel threads.

Use a verifier built at the source revision being checked and a Python environment with `cadquery-ocp`. Store evidence outside the checkout:

```sh
python3 -B tools/research/m3_acceptance.py \
  --binary "$M3_BINARY" --out "$M3_PROOF"
```

`summary.json` records every answering request or typed refusal and actual artifact hashes. Raw STEP translation bypasses caller-side repair. Independent face counts, material probes and numerical volume checks test the exported files. The near-miss midpoint lies inside OpenCASCADE's imported face tolerance, so its classifier reports a boundary point even with a smaller query tolerance. The check instead reads the two written cylinder supports as exact decimal rationals and proves their positive gap and the midpoint's positive squared radial clearance. Contact and overlap fail this check. No reader or model tolerance changes.

The volume audit uses the existing replay check's integration margin; it is not a proof of global file deviation. STL checks inspect the actual triangle bytes, directed edge pairs and the qualified file hash and bound. Field comparison remains on demand and is not requested here.

This command does not run SolidDraft or supply its preview, proof-state or export evidence. Its `parts.application-loop-required` outcome keeps that missing gate visible. Raw evidence retained privately.
