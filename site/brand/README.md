# Catallax site identity

The studio site's graphite, bone and rust-orange palette, fonts and motion are preserved in `tokens.css`. These are regular files, not a link to an external brand directory. CSS and the wireframe renderer read the same tokens.

The Catallax mark opens an isometric boundary like a C, with an orange defining point. The lowercase wordmark uses Bricolage Grotesque. JetBrains Mono is used for code and labels; Instrument Serif Italic supplies headline emphasis. Each font's OFL notice is beside its WOFF2 file in `fonts/`.

The hero, anatomy diagrams and assembly film are illustrations. They are not Catallax geometry output. Reduced motion stops ambient rotation and the ribbon, switches anatomy layers without transitions and leaves videos on their posters with playback controls.
