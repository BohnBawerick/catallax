Checkpoint 1. Where the kernel stands.

The first phase of the roadmap ended on 16 November 2026. We built the same parts in Catallax, OpenCASCADE and SMLib, and imported 3,000 public STEP files. Catallax 0.3.0 is cut from the commit these numbers measure.

Edit-chain scoreboard

Each target part is built, then built again after one dimension changes. The test parts are P0, eight hard intersection cases, and P1 to P5: a bracket, a collar, a filleted boss, a shelled tray and a flanged housing. The real parts are ten files from the public STEP census below. On each real part, every kernel drills one hole through the middle, then makes the hole 1.5 times wider.

One definition of done for all three kernels: both versions build, both STEP exports open in OpenCASCADE as valid closed solids with the right number of faces, and no independent check finds a wrong value. On a real part, the hole and the wider hole must each remove material.

Where Catallax falls short

  • The general cone and general torus test parts are refused. Catallax cannot yet trace where those surfaces cross. Both other kernels build them.
  • The filleted boss builds and exports a valid file, but one check point lands on the wrong side of the surface. The cause is not yet found.
  • The flanged housing counts as done, but 16 of its faces or edges lose their names after the edit.
  • On one real part, 00000173, the drilled hole is refused.

On three real parts the hole lands inside an existing bore, so it removes no material in any kernel. Those three count as not done for all three kernels. OpenCASCADE fails the flanged housing's fillet. SMLib fails that fillet too, along with three of the hard intersection cases and the collar's volume check.

3,000 real STEP files

The census takes 3,000 models from the public ABC collection, picked with a fixed seed, and imports every one. A file counts for Catallax only when every body in it imports, exports again as STEP, and that export passes OpenCASCADE's validity check. The check runs after the OpenCASCADE builder, which may heal pcurves, the curves that trim each face.

Import is the largest gap between Catallax and OpenCASCADE. The two figures are not measured at one tolerance: OpenCASCADE repairs each file with its default healing before the check, and its tolerances differ from Catallax's. They compare how many files each kernel opens, not accuracy.

2,590 files are refused at import, each with a recorded reason. The four most common reasons cover 1,701 files.

Numerical first, and import by tiers

Catallax used to need an exact proof for every step. Now, where an exact proof is missing or too costly, it builds within a tolerance stated before the operation, as OpenCASCADE and SMLib do. It checks the result separately at that tolerance and marks it, and its STEP file, as approximate. A numerical result is never labelled exact.

Of the 408 census files Catallax admitted at the checkpoint, 190 are certified exact and 218 are numerical approximate imports.

Import now opens a file in tiers. A file that becomes a checked solid is a complete import. A file that cannot yet become one can still open, with its surfaces kept but not checked. That surface set cannot be exported as a solid. The tier code was measured on its own full census when it landed:

Cuts on freeform solids

Lofted solids have freeform spline faces. Cutting and joining them needs the kernel to find where two such faces meet. Of 14 recorded test requests, 11 now write a checked approximate STEP file within Catallax's work target of 20 million units. The three cuts across the top of a loft are still refused, so this milestone stays open into phase 2.

In SolidDraft

The test parts P1 to P5 build in SolidDraft, take their edit, undo and redo, save, reopen with the same geometry, and export STEP. Every export opens as valid in OpenCASCADE with repair turned off.

In the browser, kernel work now runs off the page. Opening the bracket used to freeze the page for 7.4 s; the longest freeze is now about 0.2 to 0.4 s.

Catallax 0.3.0

The release is cut from the commit the checkpoint measured. It is an alpha. Downloads and checksums are on the 0.3.0 release page. Since 0.2.0 it adds:

  • STEP import of real files: numerical import of planar, cylindrical, conical and spline surfaces, per-part tolerances, repair of the file's own topology, and opening by tier.
  • Approximate STEP export for numerical results, curved faces with holes, cones and spline cut results.
  • Cuts and joins on lofted solids: 11 of the 14 recorded requests.
  • Everyday features: mixed fillet corners, hollow drafts, chamfers where three edges meet, shells with side openings, and skew holes through bevelled collars.
  • Replacing an imported STEP file while keeping the faces and edges that match.

Next: phase 2

Phase 2 adds modelling tools Catallax does not have yet: fillets between freeform faces, a NURBS surface toolkit, open surface bodies that sew, trim and thicken into solids, sweeps such as springs and threads, and direct edits on imported parts. It runs as three kernel lanes at once. One lane finishes the loft cuts, then the freeform fillets, then direct edits. One works on import, starting with sewing imported surface sets into checked solids. One builds the surface toolkit, then the sweeps. The scoreboard and the census run again at Checkpoint 2.

Every number on this page comes from the Checkpoint 1 report, which has the method, the raw tables and the commands to rerun them. The plan is in the roadmap.
