One definition of done.

Catallax, OpenCASCADE and NVIDIA SMLib, scored on the same cases by the same rule. Results are published once the fillet setup is complete and Catallax and SolidDraft are released.

The rule

A case is done when the kernel returns one valid solid, within the geometric tolerance δ of the case's reference geometry, inside the solve-time limit T. Anything else is not done.

Valid solid
One closed solid. A refusal, an error or a partial result is not done.
Tolerance δ · TBD
Largest distance allowed between the returned solid and the reference geometry. Above δ is not done.
Time limit T · TBD

Applied uniformly
