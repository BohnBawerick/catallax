One definition of done.

Catallax v0.1.5, OpenCASCADE and SMLib, run on the same 125 cases and scored by the same rule.

The rule

A case is done when the kernel returns one valid solid within T = 120 s, its authored material witnesses pass, and every sampled boundary distance to the reference is at most δ = 0.001 mm. Anything else is not done.

Tolerance δ
0.001 mm. The run also records 0.1, 0.01, 0.0001, 0.00001 mm; slide below.
Time limit T
120 s for the whole process, including start-up and STEP export. Over the limit is unsolved.
Unresolved
The check could not settle a bound, usually because the reference does not define that case yet. Not a loss for the kernel.
Applied uniformly
Same cases, same δ, same T for all three kernels. One run per kernel, no retries.

What these numbers are

Sampled checks, not a certificate over the whole part. The reference is Catallax's field definition, compiled independently of its B-rep but written by the same authors. OpenCASCADE both competes and imports every STEP file for checking.

Run on a shared development host. Solve times are only checked against T; they are not a speed ranking.
