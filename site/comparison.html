Construction and one parameter edit on thirteen fixed P0–P5 parts. Timings and correctness are reported separately. A quick refusal is not a completed part.

Measured on quiet benchmark machine, Intel(R) Core(TM) i7-14700. Linux-6.6.87.2-microsoft-standard-WSL2-x86_64-with-glibc2.39. One core, 1 warmup and 3 measured samples per tool and part. Catallax work allowance: 100,000,000 per phase. Committed measurements and checksums.

Build and edit time

Median successful build time. Edit means a complete script rebuild for Catallax, CadQuery, smlibpy and Pali Ijo; SolidCraft uses its native parameter-change command. Startup is outside internal build timers and retained in the raw run. Construction and edit can include tool-specific validation or display work. These are application operations, not isolated kernel instruction timings.

CadQuery was selected for its released headless Python API, solid primitives, blends, shells and STEP export. smlibpy is a public MIT Python tool bundling SMLib under Apache-2.0. Pali Ijo is MIT; upstream publishes no release archive or pub.dev package, so its official 0.1.2 source snapshot is pinned by commit and checksum and compiled with Dart 3.13.7. No upstream code or assets are copied into this site or repository.

OpenCASCADE is both CadQuery's modeling kernel and the STEP checker. The checker uses cadquery-ocp 8.0.1.1.0; CadQuery uses 7.8.1.1.post1. Properties and membership are checked against independently authored analytic definitions, not another kernel's constructed part. Four P0 curved-intersection families have analytic membership but no implemented property formula here: block-sphere, crossing-pipes, general-cone and general-torus. Their property cells remain unmeasured. P5's junction blend meets the countersink openings, so a complete trimmed-blend oracle is unavailable here; its properties and membership remain unmeasured rather than checking a full-torus approximation. The other eight families use elementary property formulas and converged quadrature of smooth analytic fillet sections. Numerical diagnostics use the unchanged absolute 1e-6 or relative 1e-8 allowance, not a modeling tolerance or exactness certificate.

Membership uses OpenCASCADE to classify imported STEP on a fixed 216-point grid, with expected values from analytic solid predicates. It measures that export/import/classification path, not native point queries in the producing tool. Boundary points remain unresolved. Passing samples do not prove set equality. STEP is opened without repair and checked for topology validity and the producing tool's face count. Names check string survival, not semantic correspondence. CadQuery and smlibpy expose no persistent per-face/edge rebuild-name contract here; Pali Ijo's ancestry IDs are process-local, so those name checks are not run. Missing operations are not approximated and failed prefixes are not exported as answers.

Tool order: rotating tool order, reversed on odd samples. One-minute load averages ranged from 1.05 to 1.87; the machine label alone does not prove an idle CPU. Process timeouts are incomplete, never geometric refusals. No ratios or general speed ranking are asserted. Scripts, release pins and rerun commands.
